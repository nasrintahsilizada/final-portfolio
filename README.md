# Nasrin Tahsilizada - Portfolio

A modern, accessible, and interactive portfolio website built with React, showcasing projects, skills, and professional experience.

## 🎨 Color Palette

- **Purple**: `#B7A3E3` - Primary brand color
- **Blue**: `#C2E2FA` - Secondary color
- **Cream**: `#FFF1CB` - Highlight color
- **Coral**: `#FF8F8F` - Accent color

## ✨ Features

### Core Functionality
- **Responsive Design**: Fully responsive across all devices
- **Dark/Light Theme**: Toggle between themes with localStorage persistence
- **Smooth Animations**: Framer Motion animations throughout
- **Accessible**: WCAG compliant with ARIA labels, keyboard navigation, and semantic HTML
- **Performance**: Optimized images, lazy loading, and efficient rendering

### Pages & Components
- **Home**: Hero section, featured projects, skills overview, and CTA
- **About**: Bio, skills, experience timeline, and testimonials
- **Projects**: Filterable project grid with search functionality
- **Project Detail**: In-depth project information with tech stack and progress
- **Contact**: Contact form with file upload and validation
- **404**: Custom not found page
